Fees

Set one monthly fee for each class. Every student in that class pays it. The first month is paid when the account is created, and the next fee falls due on the same date every month.

Reminders go out automatically on each due date, the next time this panel is opened. You can also send them now.

Monthly fee for each class

Enter the amount every student of that class pays each month. Leave a class empty if it has no fee.

One-time fees
